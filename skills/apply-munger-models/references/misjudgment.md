# Misjudgment cues

Munger names 25 tendencies in [*The Psychology of Human Misjudgment*](https://assets.stripeassets.com/fzn2n1nzq965/0RUnI35jpt78x10nvlO2Y/b66a46dba182182a2a0082213eafc634/SP_PCA-ZINE_2023_11_27.pdf). Use this cue sheet to choose relevant checks, not to label a person. These are operational paraphrases, not quotations.

| Munger's tendency | Check for |
| --- | --- |
| Reward- and punishment-superresponse | A metric, commission, promotion or penalty driving behavior opposite the stated goal. |
| Liking/loving; disliking/hating | Affection or aversion substituting for evidence. |
| Doubt-avoidance | Reaching closure mainly to escape ambiguity. |
| Inconsistency-avoidance | Defending a public or sunk commitment after new evidence. |
| Curiosity | Whether genuine exploration is encouraged or prematurely closed. |
| Kantian fairness | Reactions to perceived unfairness outweighing the underlying tradeoff. |
| Envy/jealousy | Relative status replacing absolute outcomes. |
| Reciprocation | A favor or slight changing judgment of unrelated merits. |
| Influence-from-mere-association | Transferring a person's or brand's halo to an unsupported claim. |
| Pain-avoiding psychological denial | Avoiding data because it would force an unpleasant decision. |
| Excessive self-regard | Overestimating one's forecast, work, team or control. |
| Overoptimism | The upside story lacks a credible causal path or comparable evidence. |
| Deprival-superreaction | A loss or near-win dominates proportionate analysis. |
| Social-proof | Copying peers without checking whether their conditions match. |
| Contrast-misreaction | Evaluating against a manipulated anchor instead of a meaningful baseline. |
| Stress-influence | Urgency, fatigue or pressure changes the apparent quality of a choice. |
| Availability-misweighing | A vivid anecdote substitutes for frequency. |
| Use-it-or-lose-it | A capability atrophies because it is not practiced. |
| Drug-misinfluence; senescence-misinfluence | Impaired state or age-related limits when directly relevant; avoid speculation about individuals. |
| Authority-misinfluence | Deference replaces independent inspection of evidence. |
| Twaddle | Empty confident talk crowds out the decision or evidence. |
| Reason-respecting | A thin reason makes a request seem more valid than its substance. |
| Lollapalooza | Several tendencies reinforce one another to produce an outsized result. Name each mechanism and its evidence. |

## Bias-check protocol

1. Identify a specific cue, not merely a label.
2. Offer an alternative explanation.
3. Check the user's and analyst's preferred conclusions symmetrically.
4. Match the antidote to the cue: independent forecast, precommitted threshold, dissenting evidence, rest period or changed incentive.
5. Note when the cue is absent.

Treat a combined effect as an inference until behavior is observed.
